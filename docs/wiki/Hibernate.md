# Capture Hibernate SQL

The [Hibernate example](https://github.com/icher-g/assert-sql/blob/main/assert-sql-examples/README.md#hibernate-sql-capture) targets
Hibernate ORM **6.6.59.Final** and its public `StatementInspector` hook. Copy
[HibernateSqlCapture](https://github.com/icher-g/assert-sql/blob/main/assert-sql-examples/src/test/java/io/assertsql/examples/fixtures/HibernateSqlCapture.java)
into your test sources. It records SQL verbatim and returns it unchanged to Hibernate.

The runnable [HibernateExampleTest](https://github.com/icher-g/assert-sql/blob/main/assert-sql-examples/src/test/java/io/assertsql/examples/HibernateExampleTest.java)
creates mapped users/profiles, persists fixture data, and executes HQL against H2.
It asserts the SQL generated by Hibernate and separately checks returned rows,
including a user without a profile and an INNER JOIN regression.

With a `sessionFactory` from the included
[HibernateDatabase](https://github.com/icher-g/assert-sql/blob/main/assert-sql-examples/src/test/java/io/assertsql/examples/fixtures/hibernate/HibernateDatabase.java)
fixture, register a fresh capture on the session used by the operation. `ExampleUser`
maps to `users` and `tenantId` maps to `tenant_id`:

```java
import io.assertsql.Expect;
import io.assertsql.examples.fixtures.HibernateSqlCapture; // Use the package of your copied helper.
import java.util.List;
import static io.sqm.core.dialect.SqlDialectId.ANSI;
import static org.junit.jupiter.api.Assertions.assertEquals;

var capture = new HibernateSqlCapture();
try (var session = sessionFactory.withOptions()
    .statementInspector(capture)
    .openSession()
) {
    var transaction = session.beginTransaction();
    try {
        session.createQuery("select u.id from ExampleUser u where u.tenantId in :tenantIds order by u.id", Long.class)
            .setParameterList("tenantIds", List.of(42L))
            .getResultList();
        var statements = capture.statements();
        assertEquals(1, statements.size(), "Expected one SQL statement from this operation.");
        Expect.sql(ANSI)
            .as("Hibernate tenant lookup")
            .select()
            .table("users")
            .column("tenant_id")
            .parameterCount(1)
            .positionalParameterCount(1)
            .build()
            .assertMatches(statements.getFirst());
    } finally {
        transaction.rollback();
    }
} finally {
    capture.clear();
}
```

The normal build runs these real Hibernate/H2 tests. Hibernate generates and executes
the queries; Assert SQL inspects the captured text. The fixture's SQL uses the subset
accepted by SQM's ANSI parser; choose the corresponding dialect for your application.
The hook captures JDBC placeholders such as `?`, not their bind values.

The examples cover both IN predicates and compact equality such as `tenant_id=?` emitted by Hibernate. SQM 0.5.1 parses the unchanged captured SQL.

Use one capture per session/test to isolate parallel tests. A factory-wide capture
must be thread-safe and needs additional coordination to separate test operations.
See the example documentation for registration choices and capture cleanup.
